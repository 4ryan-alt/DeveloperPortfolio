# DeveloperPortfolio

My CS Fundamentals (CSE103) lab portfolio — K.R. Mangalam University, B.Tech CSE (AI and ML), Section E.

A collection of everything built across Labs 1–4: Linux and C/Python work, shell scripts, a Git + API project, and my developer portfolio site.

## Structure

| Folder | Contents |
|---|---|
| `Linux/` | Lab 1 — C vs Python compilation: `hello.c`, `hello.py`, and terminal proof logs |
| `ShellScripts/` | Lab 2 — Bash scripts: loops, file automation, debugging (`loop_script.sh`, `auto_files.sh`, `debug_script.sh`, `debug_defensive.sh`) |
| `API/` | Lab 3 — Git + API project: `main.py`, `users.json`, changelog and docs |
| `Portfolio/` | Lab 4 — Developer portfolio site (`index.html`), resume, learning roadmap |
| `Screenshots/` | GitHub profile and repository screenshots |

## How to run

```bash
# C program
gcc Linux/hello.c -o hello && ./hello

# Python program
python3 Linux/hello.py

# Shell scripts
bash ShellScripts/loop_script.sh
bash ShellScripts/auto_files.sh

# API project
python3 API/main.py
```
